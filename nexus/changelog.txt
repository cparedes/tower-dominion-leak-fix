1.4.0
- New: AreaOfEffectLeakFix, which fixes the frame rate sinking over long games. Bomb impacts no longer leave objects behind that make Unity's audio mixer slower every frame (0 leftover objects and 0–2% mixer cost over 58 min, versus 348 objects and 6–10% of the main thread after 16 min without it).

1.3.0
- New: MelonLoader support (0.6+, tested 0.7.3). The same five fixes, built as a MelonLoader mod. Settings live in UserData/MelonPreferences.cfg.
- No behaviour changes on BepInEx.

1.2.0
- New: AudioInstanceLeakFix, so UI sounds (reroll, click, hover, select) no longer go silent in long sessions.
- New: ManagedDataCacheFix, which removes the building-select stutter (40–65 ms → 1–2 ms) and recurring ~66 ms hitches.
- New: AssetUnloadThrottleFix, which removes the 20–30 ms hitch after deselecting a building or closing a panel.

1.1.0 (first release)
- EnemyPoolLeakFix: enemy objects (and other pooled objects with the same bug) are deleted when wave changes shrink the pools, instead of leaking.
- UnlockConditionLeakFix: removes duplicate unlock-condition listeners created when the save loads.
